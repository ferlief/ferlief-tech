# Conjunto de avaliação

**A preencher.** Congelar antes de ajustar qualquer parâmetro.

Formato: uma pergunta por linha, com a passagem esperada, ou
`NENHUMA` quando a pergunta não deve ser respondida.

## Respondíveis

| pergunta | passagem esperada |
|---|---|
| o que é o porta-voz? | 010-este-projeto#0 |
| por que não usou embeddings? | 010-este-projeto#2 |
| quanto custa manter isso no ar? | 010-este-projeto#1 |
| como o site troca de layout? | 020-ferlief-tech#1 |
| *(a completar — mínimo de 30 antes de calibrar)* | |
